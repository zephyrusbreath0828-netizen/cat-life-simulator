# 猫部屋シミュレータ v1.1.0

太陽が差し込むアパートの一室を舞台に、猫の「ミケ」が欲求に従って自律的に
動き回るバーチャルペットシミュレータ。

**スタック:** React 19 · TypeScript · React Three Fiber 9 · drei 10 · Three.js 0.187 · Zustand 5
外部アセットなし（テクスチャは実行時に Canvas へ描画）。本番ビルドは
**単一の自己完結 HTML** としてブラウザ内だけで動作する。

## 変更履歴

### v1.1.0 — 欲求システムと家具インタラクション
- 欲求 5 種（空腹度・喉の渇き・眠気・遊びたい度・好奇心）を追加。時間経過で増加する
- 行動 AI: 最も高い欲求が閾値 (80) を超えると、対応する施設へ移動して行動する
  （空腹→餌皿で食事 / 渇き→給水器で飲水 / 眠気→猫ベッドで睡眠 /
    遊びたい→ボールで遊ぶ / 好奇心→窓を見て部屋を探索）
- 家具追加: 給水器・猫ベッド・ボール。アニメーション追加: 食事・飲水・遊ぶ・窓見
- UI: 情報パネルに欲求 5 種の数値と現在時刻を表示、設定画面（カメラ設定・
  開発用デバッグ・バージョン表示）を追加、画面右下に「Version v1.1.0」
- デバッグメニュー: 各欲求を即時 100 にできるボタン群

### v1.0.0 — 3D アパートと基本行動
- 3D 部屋（窓・ソファ・キャットタワー・餌皿・給水器ほか）、自由視点/追跡カメラ、
  待機・歩行・お座り・睡眠のアニメーション、ランダム行動ロジック、日本語 UI

## 操作

| 操作 | 動作 |
|---|---|
| ドラッグ | 視点回転 |
| スクロール | ズーム（0.6〜11 m） |
| `W A S D` | 視点のパン（自由視点モード時） |

画面下のボタン: **自由視点** / **猫を追跡** / **一時停止** / **設定**

URL パラメータ（デバッグ・自動テスト用）:
`?nointro=1` 導入カード省略 · `?follow=1` 追跡カメラで開始 · `?pause=1` 一時停止で開始 ·
`?hunger=100` など欲求の初期値指定

## アーキテクチャ（今後の拡張を前提した設計）

```
src/
  version.ts             ★ アプリ名・バージョン（画面表示と共通の一元管理）
  i18n/
    ja.ts                日本語リソース（表示文字列 + 時間の整形）
    index.ts             言語レジストリ（setLocale で切替）
  sim/
    catStore.ts          Zustand ストア: 名前・フェーズ・一時停止・カメラモード・
                         経過時間・欲求 5 種（tick / decreaseNeed / setNeed）
    launchParams.ts      URL パラメータ（デバッグ・テスト用）
  cat/
    runtime.ts           毎フレーム更新される高頻度値（位置・向き）のシングルトン
    behavior/
      scheduler.ts       ★ 意思決定レイヤー: 閾値 80 以上の最欲求を優先し、
                         施設行動を返す。自由行動は重み付きランダム
      CatController.tsx  行動の実行: 移動積分・旋回・衝突解決・施設の使用・完了判定
    model/
      config.ts          ★ モデル設定（procedural / gltf の 1 行切替え）
      types.ts           CatModelProps（モデル実装の共通契約）
      ProceduralCat.tsx  手続き猫（8 アニメーション）
      GltfCat.tsx        GLTF/GLB アダプタ（クリップ自動検出・クロスフェード）
      index.tsx          設定に応じてモデルを選択
  systems/
    CameraRig.tsx        自由視点 / 猫を追跡カメラ
    AutoHide.tsx         ドールハウス表示（壁の自動非表示）
    collision.ts         円 vs AABB の衝突解決
    textures.ts          手続きテクスチャ
  world/                 部屋・家具・餌皿/給水器・猫ベッド/ボール・キャットタワー
  ui/HUD.tsx             日本語 UI（情報パネル・ボタン・設定画面・バージョン表示）
```

### 今後の拡張（複数猫・性格・年齢・体重・飼い主・学習）に向けて

1. **猫プロファイルの分離**: ストアの `name` と欲quakeの既定値を
   `CatProfile`（name / personality / age / weight / owner...）へ発展させ、
   猫 1 匹 = プロファイル 1 つ + ランタイム 1 つの構造にする。
   複数猫は CatController をインスタンス毎にマウントするだけでよい。
2. **性格**: scheduler の `NEXT_WEIGHTS` と欲求の成長率をプロファイルから
   生成する（例: 活発な猫は遊びたい度の成長が速い）。
3. **学習機能**: chooseNextAction の結果（行動後の欲求変化）を記録し、
   重みを補正する履歴テーブルを scheduler に追加する。
4. **新しい施設・欲求**: layout.ts の POI と scheduler の DRIVE_ACTIONS に
   1 行ずつ追加するだけで、移動→行動→欲求回復のループが自動で効く。
